    사용법 · 단축키

    • 점은 사건이 일어난 곳입니다. 클수록 영향이 크고, 흐릴수록 지난 소식입니다.
    • 선은 국가 간 관계입니다. 뉴스나 선을 고르면 그 선이 분야 색(위쪽 분야 버튼의 색)으로 강조됩니다.
    • 작은 고리는 관련국·연결 지점입니다. 뉴스를 고르면 나라 이름과 관계가 함께 표시됩니다.
    • 점이나 선, 목록의 뉴스를 누르면 상세 정보가 열리고 지구본이 그곳을 비춥니다.
    • 국가 이름표나 국경을 누르면 그 나라 뉴스만 모아 봅니다. 다시 누르면 전체로 돌아갑니다.

    개발자 API · 데이터 파이프라인

    REST 웹훅으로 이벤트를 보내면 SSE로 지구본에 즉시 표시됩니다. (python server.py 로 실행 시)

    원클릭 테스트 — 누르면 지구본에 바로 나타납니다

    POST 웹훅 URL http://localhost:8080/api/events
    cURL 예시 
    curl -X POST http://localhost:8080/api/events \
  -H "Content-Type: application/json" \
  -d '{
    "title": "[테스트] 호르무즈 해협 군사 억제 연합 순찰 전개",
    "category": "conflict",
    "primaryCountry": "IR",
    "countryCodes": ["US", "IR"],
    "summary": "다국적 연합 해군이 주요 해상 통로 순찰을 전면 개시했습니다.",
    "impactScore": 88,
    "demo": true
  }'

    내 컴퓨터(127.0.0.1)에서는 기본적으로 토큰 없이 동작합니다. 서버를 외부에 공개하면(--host 0.0.0.0) 쓰기 요청에 토큰이 필요합니다: -H "Authorization: Bearer <토큰>"
